# Schoolmap

학교 실내 위치 추정을 위한 웹 프로토타입입니다.

## 실행
GitHub Pages 또는 로컬 정적 웹 서버에서 `index.html`을 엽니다. 브라우저에서 지도 이미지 파일을 선택해 표시할 수 있습니다.

## 현재 기능
- 지도 이미지 불러오기
- 현재 위치 마커 표시
- 휴대폰 방향 센서 기반 시야 방향 화살표
- 가속도계 기반 간이 걸음 추정(PDR)

## 현재 설정과 한계
- 초기 위치: 제공된 항공사진 기준 약 X 75.42%, Y 90.17%
- 이미지 위쪽 방향: 실제 남동쪽(방위각 약 135°)으로 가정
- 이동 거리/픽셀 축척은 임시값입니다.
- 현재 PDR은 실험용 추정치이며, 실내에서 정확한 위치를 보장하지 않습니다.
- 제공된 사진 파일은 아직 저장소에 별도 업로드되지 않았으므로 실행 후 지도 이미지 선택이 필요합니다. 추후 평면도와 함께 기준점 및 축척을 보정합니다.
